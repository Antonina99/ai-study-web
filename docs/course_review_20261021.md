# 课程逐门语境与事实复核 · 2026-10-21

## 复核范围

接续 2026-09-19 的 RAG 学习版，对其余 14 门已入库课程的 4,264 个原文片段逐门完整阅读，结合导读检查覆盖，再生成独立学习资产。原始 DOCX、原文编号与逐字稿保持不变。复核范围不包含未入库的 31 门规划课程，也不将 `_笔记.docx` 当成新原文。

本次区分三个产物：原始转写用于追溯；学习版允许去重复、去闲聊与重组主题；外部事实校订和未知项单独说明。完成文字通读不等于完成音频校对，无法确认的身份、型号、内部案例或演示结果不会被包装成确定事实。

## 工具与证据流程

1. 从当前 DOCX 解析结果冻结 14 门原文/导读副本及 SHA-256 指纹。
2. 实际执行 transcript-fixer Stage 1：14 门均为 applied=0、deferred=0、review_enqueued=0，boundary_check_active=true。词典零命中不代表无错误；没有将 Stage 1 作为完整清洗结果。
3. 每门完整通读原文与导读，核验关键定义、机制、条件与数值语境；对公开技术实体采用官方文档或原论文。
4. 学习版保留 `citation_ids` 与原始起始时间；校订依据、观点边界及未决项记录在 `notes` 和 `review_audit`。
5. 通过独立冷复核检查学习版残留问题，再核对来源、结构、网页加载与测试结果。

本地工作证据保存在被 Git 忽略的 `.course_review/20261021/`；对外发布的是 `assets/course_reviews/` 中的学习资产和本记录，不重复提交原文副本或本机工具数据库。没有新增网页运行依赖，也没有将课程内容发给付费模型 API；联网核验使用公开技术关键词。
